Weather + Heat

濕熱與陣雨是週五最大變數

官方天氣預報把週五降雨機率列為 50%
Formula1.com 官方天氣稿指出，週五氣溫約 23–32°C，體感溫度可達 ~37°C；降雨機率約 50%，賽道溫度可能很高（官方提及 ~50°C+）。這意味 FP1、FP2 的成績可能受時段與賽道條件強烈干擾。
週六降雨約 40%，週日約 30%
官方天氣預報顯示週六雨機率約 40%，週日約 30%。Sepang 歷史上常在午後出現短時間陣雨，車隊需在週五練習中同時準備乾地與濕地設定。
賽道近期整平作業後，抓地力需重新建立
Need to Know 確認賽道表面近期有整平與清潔作業。週五初期抓地力偏低，車隊很難用第一組 run 就判定真正速度層級，長距離退化判讀比單圈成績更有價值。

Friday Watchlist

今天真正該盯的五條線

1. Sepang 回歸後，現行世代賽車幾乎無真實參考，週五練習比平常更關鍵
官方 Need to Know 特別點出，Sepang 自 2017 年後睽違回歸，現行 2026 規則賽車在這條賽道幾乎無歷史數據。車隊需在 FP1、FP2 快速建立輪胎窗口、動力部署與長距離基準，週五數據的可信度會直接影響週六排位與週日正賽策略。
2. 濕熱＋陣雨風險＋高賽道溫度，長距離窗口比單圈 headline 更重要
官方天氣預報週五降雨機率 50%，氣溫 23–32°C，體感可達 ~37°C，賽道溫度可能超過 50°C。這種條件下，輪胎溫度窗口與長距離退化判讀比單圈最快更有價值。若週五成績受局部雨勢干擾，真正的速度層級要等週六才會顯影。
3. Mercedes 內部：Antonelli 仍領先 66 分，但 Russell Baku 縮分後壓力上升
Russell 在 Baku 從桿位守到終點勝利，Antonelli 從排位撞牆後的 P16 爬回 P5。積分差距從 81 分縮到 66 分，Mercedes 需在雪邦的濕熱環境中讓雙車都維持穩定節奏，避免積分戰在長距離賽事中快速改變。
4. Red Bull：Verstappen 尋求本季首勝，Hadjar 因動力單元零件超配額本週末受 5 格罰格
Verstappen 在 Baku 從 P8 追到 P2，展現直線速度優勢。Sepang 的 928 公尺主直道若能讓 Red Bull 延續部署效率，Verstappen 有機會爭取本季首勝。Hadjar 本週末因更換動力單元零件（已超過本季配額）受 5 格罰格處罰；Colapinto（Alpine）則因 Baku 造成碰撞事件同樣受 5 格罰格。
5. 賽道整平作業後，初期抓地力偏低，長距離退化判讀比第一組 run 更重要
Need to Know 確認賽道表面近期有整平與清潔作業，週五初期抓地力偏低。車隊很難用第一組 run 就判定真正速度，需透過多組長距離模擬建立可信基準。這讓 FP2 的長距離數據比 FP1 的單圈成績更有參考價值。
What Changed

Baku 站後，排名故事怎麼改寫

  • Russell 在 Baku 桿位勝利拿 25+1 分，把 Antonelli 領先從 81 分縮到 66 分。
  • Antonelli 從排位撞牆後的 P16 爬回 P5，證明 Mercedes 賽車速度仍在，但壓力開始顯影。
  • Verstappen 從 P8 追到 P2，Hadjar 復出拿 P3，Red Bull 在 Baku 雙車登台證明直線優勢開始顯影。
  • Norris 重啟被 Colapinto 撞退賽，McLaren 損失前五機會，Piastri 失誤掉到 P14，車隊積分第三面臨壓力。
  • Hadjar（Red Bull）因更換動力單元零件超配額本週末受 5 格罰格；Colapinto（Alpine）因 Baku 造成碰撞受 5 格罰格。
Editorial Angle

這份 Friday dispatch 的主題

巴林站（馬來西亞）週五的重點不是誰先刷出最快圈，而是 Sepang 這種長直道、濕熱、氣候多變的環境，會不會把 Baku 後累積下來的積分壓力直接顯影。Mercedes 仍握有雙榜主導權，但 Russell 的縮分速度與 Antonelli 的排位撞牆，讓每一次失誤都變成昂貴事件。

如果今天官方結果頁尚未公布完整數據，真正有價值的訊號會是誰能在濕熱與變天裡維持可重複的長距離節奏。這通常比 Friday headline 更接近週日真相。
